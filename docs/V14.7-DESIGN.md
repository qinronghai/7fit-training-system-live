# 7Fit Training System V14.7｜F111 自由组合编课矩阵设计规范

状态：设计冻结候选  
基线：V14.6.3｜十大动作模式整合版  
定位：将现有 F111 从“8 个固定 Recipe”升级为“8 个官方预设 + 5×4 自由组合矩阵 + Level→Tier/Grade 映射 + 动态辅助推荐”的教练编课系统。  
目标：解决单腿模式只有膝主导、F111 主模式组合过少、L/T/S/CORE 等级关系不统一、D1/D2 辅助动作随模板固定的问题。

---

# 1｜为什么要做 V14.7

当前 F111 有 8 个固定 Recipe：

1. 下肢推 + 水平拉 + 支撑
2. 下肢推 + 垂直拉 + 支撑
3. 髋铰链 + 水平拉 + 支撑
4. 臀伸 + 垂直拉 + 单侧支撑
5. 单腿 + 水平拉 + 动态支撑
6. 下肢推 + 水平推 + 支撑
7. 髋铰链 + 垂直推 + 单侧支撑
8. 单腿 + 垂直拉 + 支撑

这些模板能直接上课，但存在两个结构问题：

- 「单腿模式」当前 T1–T4 全部是单腿蹲 / 分腿蹲类，缺少单腿髋铰链主链；
- 下肢与上肢的组合被 8 个 Recipe 固定，无法覆盖所有合理组合。

V14.7 不删除这 8 套课程，而是把它们重新定义为：

> **7Fit 官方推荐预设**

同时新增：

> **自由组合编课**

---

# 2｜F111 定义不变

F111 继续表示：

> **一下肢 + 一上肢 + 一支撑**

完整 60 分钟训练结构仍然是：

```text
2F PREP
↓
1F STRENGTH
A 下肢主项
B 上肢主项
C 支撑模式
D1 下肢辅助
D2 上肢 / 肩胛 / 手臂辅助
CORE 核心任务
↓
2F RECOVERY
↓
POST CARDIO（按需要）
```

因此 V14.7 是**选课方式升级**，不是推翻 F111。

1. 蹲

4. 单腿

> **十大动作模式总数仍然是 10，不增加第 11 个模式。**

# 4｜新增单腿拉 T1–T4 主链

正式建立「单腿拉 / Single-Leg Hinge」主链。

| Tier | 标准动作 | 训练重点 |
|---|---|---|
| T1 | 扶持单腿髋铰链（徒手） | 学习单侧髋折叠、骨盆保持正向 |
| T2 | 扶持哑铃单腿罗马尼亚硬拉 | 在外部支撑下加入轻负重 |
| T3 | 独立哑铃单腿罗马尼亚硬拉 | 独立平衡、负重髋铰链、抗旋转 |
| T4 | 高阶负重单腿罗马尼亚硬拉 | 更高有效负荷、稳定控制、RIR 1–2 |

T4 不强制使用杠铃。

允许根据会员能力使用：

- 对侧单哑铃；
- 双哑铃；
- 更高负荷单哑铃；
- 停顿 / 慢离心处方。

T4 的本质是：

> **高水平单侧髋铰链能力，而不是器械升级。**

# 8｜Session Level → Main Tier 映射

Session L 与主动作 T 不是绝对等号。

正式规则：

| Session | 推荐 T | 常规候选 | 手动退阶 |
|---|---|---|---|
| L1 | T1 | T1 | — |
| L2 | T2 | T1–T2 | — |
| L3 | T3 | T2–T3 | 可显示 T1 |
| L4 | T4 | T3–T4 | 可显示 T1–T2 |

原则：

> **Session L 决定常规候选窗口，不禁止合理退阶。**

例如：

```text
Session L3
A 单腿拉｜T3
B 水平推｜T2
```

是合法课程。

---

# 9｜Session Level → SUPPORT Grade 映射

SUPPORT 等级表示支撑任务复杂度，不等于会员总等级。

正式映射：

| Session | 默认 | 常规候选 | 扩展候选 |
|---|---|---|---|
| L1 | S1 | S1–S2 | — |
| L2 | S2 | S1–S3 | — |
| L3 | S3 | S2–S4 | S5 |
| L4 | S4 | S3–S5 | S6 |

S1–S6 定义：

```text
S1 撑住 / 基础静态
↓
S2 减少支点
↓
S3 动起来 / 动态支撑
↓
S4 身体位移
↓
S5 旋转 / 高抗旋转
↓
S6 单侧、多条件整合
```

扩展候选需要显示：

> 超出当前 Session 常规推荐范围

但不禁止教练选择。

---

# 10｜Session Level → CORE Grade 映射

CORE Grade 和 Session L 即使都是 L1–L4，也不是机械等号。

| Session | 推荐 Core Grade | 常规候选 |
|---|---|---|
| L1 | CORE-L1 | L1 |
| L2 | CORE-L2 | L1–L2 |
| L3 | CORE-L2 / L3 | L2–L3 |
| L4 | CORE-L3 | L2–L4 |

保留规则：

> **Session L4 不代表 CORE 必须使用 L4。**

CORE 选择顺序：

```text
先选 Core Demand
↓
再按 Session Level 过滤 Grade
↓
再选具体动作
```

# 11｜Core Demand 选择

自由编课必须提供 Core Demand：

- 抗伸展

- 抗侧屈
- 动态旋转

例如：

```text

↓

```

# 16｜Conflict 升级

自由组合继续使用原 Conflict 引擎，并新增 Composer 级检查。

## HARD FAIL

- 同一正式 Session 重复同一标准动作 ID；
- 正式力量槽位使用不允许的 route；
- 动作状态不可自动编排；
- A 与 B 不符合所选主模式。

## WARN

保留：

- Tier 改变
- 模式堆叠
- 器械集中
- Impact 集中
- Load Family 集中
- Muscle Concentration

新增：

### `AUX_PATTERN_DUPLICATION`

当 D1 / D2 再次加入高负荷主模式，明显复制 A / B 时：

> 辅助动作与主项模式重复，请确认是否有意增加该模式训练量。

### `GRADE_OUTSIDE_NORMAL_WINDOW`

例如 L3 选择 S5：

> 当前支撑等级高于 L3 常规 S2–S4 范围，请确认会员已具备相应能力。

这两个都是 WARN，不是 FAIL。

# 22｜自由组合 Session 不预生成 80 套静态数据

不建议创建：

> 20 个组合 × L1–L4 = 80 套硬编码 Session

原因：

- 会重复大量 slots / options；
- D1/D2 本来就是动态的；
- 后续组合增加时维护成本高。

改为运行时 Resolver：

```js
V14Composer.resolve({
  level: "L3",
  lowerMode: "single_leg_hinge",
  upperMode: "horizontal_push",
  selections: {}
});
```

返回：

```js
{
  compositionId,
  level,
  slots,
  slotOptions,
  prep,
  foam,
  anatomySummary,
  conflict
}
```

# 24｜State

自由组合使用独立 state namespace：

```js
composerSelections
```

不得覆盖旧：

```js

```

因此：

- 官方预设仍按旧 Session 工作；
- 自由组合有独立选择状态；
- 切换二者不互相污染。

# 26｜复制功能

自由组合完整课程必须支持：

```text
复制教练版
复制会员版
```

教练版继续遵守 V14.6.2 规则：

> **动作名｜等级**
>
> 组数 × 次数 / 时间｜RIR

不复制器械、楼层、内部 ID。

例如：

```text
A｜独立哑铃单腿罗马尼亚硬拉｜T3
3组 × 8–10次/侧｜RIR 2

B｜器械推胸｜T2
3组 × 10–12次｜RIR 2–3

C｜高位平板交替触肩｜S3
3组 × 8次/侧
```
