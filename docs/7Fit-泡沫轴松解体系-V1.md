# 7Fit 泡沫轴松解体系 V1

## 定位

泡沫轴位于 F111 的 `2F PREP` 第一层：**先按当天主训练主要肌群选择软组织松解部位，再进入动态活动、激活和动作模式复习。**

泡沫轴不使用 T1–T4 或 P1–P4 作为自身难度等级。它的核心不是“越高级滚得越复杂”，而是：

- 与当天 A / B 主训练主要肌群匹配；
- 只选择当天明显紧张、影响动作准备的 1–3 个部位；
- 每个部位约 30–45 秒，不做到高疼痛和疲劳；
- 不改变会员八大主动作模式 T1–T4 能力等级。

## 八大模式匹配逻辑

- **蹲**：大腿前侧 → 大腿内侧 → 小腿 → 臀部 → 大腿外侧 → 竖脊肌旁（胸腰段）
- **髋铰链**：大腿后侧 → 臀部 → 竖脊肌旁（胸腰段） → 大腿内侧
- **髋伸展**：臀部 → 大腿后侧 → 大腿外侧 → 大腿内侧
- **单腿**：臀部 → 大腿内侧 → 大腿外侧 → 大腿前侧 → 小腿 → 大腿后侧
- **水平推**：胸大肌 → 肩部 → 肱三头肌
- **垂直推**：肩部 → 肱三头肌 → 胸大肌
- **水平拉**：背阔肌/背侧 → 肱二头肌 → 肩部 → 竖脊肌旁（胸腰段）
- **垂直拉**：背阔肌/背侧 → 肱二头肌 → 肩部

## 安全边界

- **大腿外侧**：系统按“股外侧肌 / 阔筋膜张肌周围软组织”处理，不以直接碾压髂胫束为目标。
- **竖脊肌**：统一命名为“竖脊肌旁（胸腰段）”，只处理脊柱两侧肌肉，不直接滚压腰椎正中、棘突或骨性突起。
- **上臂**：肱二头肌 / 肱三头肌松解避开腋窝、肘窝和肘尖等神经血管或骨性区域。
- 出现锐痛、麻木、放射痛或急性损伤表现时停止。
