# V14.7 F111 自由组合编课矩阵 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 8 个官方 F111 预设和 32 套既有 Session 的前提下，新增单腿拉 T1–T4、5×4 自由组合矩阵、Session Level→T/S/CORE-L 映射、动态 D1/D2 推荐和完整复制/冲突/PREP/Foam/Anatomy 链路。

**Architecture:** `data/system-data.js` 新增单腿拉节点与 `composer` 配置；`js/composer.js` 作为纯解析器，根据 level/lower/upper 生成 6 槽课程候选；`views-coach.js` 增加官方预设/自由组合双入口与响应式矩阵 UI。旧 `sessions`/`sessionSelections` 不改，自由组合使用独立 `composerSelections`。

**Tech Stack:** static HTML/CSS, vanilla JavaScript, Node.js runtime tests, pytest.

**Spec:** `/mnt/data/7Fit_Training_System_V14.7_F111自由组合编课矩阵设计规范.md`

## Global Constraints
- 十大动作模式仍为 10 个；“单腿拉”是第 04 单腿模式的编课子模式，不新增第 11 模式。
- 8 个官方 Recipe 和 32 套旧 Session/旧 URL 全部保留。
- Session L 只决定推荐窗口，不与 T/S/CORE-L 做机械等号。
- SUPPORT 映射：L1 S1/S1–S2；L2 S2/S1–S3；L3 S3/S2–S4（扩展 S5）；L4 S4/S3–S5（扩展 S6）。
- CORE 先按 Core Demand，再按 Grade 过滤；L4 不强制 CORE-L4。
- 自由组合不生成 80 套静态 Session，必须运行时 resolve。
- 复制教练版继续输出“动作名｜等级 + 组数×次数/时间 + RIR”，不输出器械、楼层、内部 ID。
- 新增 4 个单腿拉动作必须有 action/actionDetails/anatomy/prescription/route/status/tier/replacement metadata。
