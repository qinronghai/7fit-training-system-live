# 7Fit Training System V14｜Information Architecture Rebuild

状态：设计冻结候选  
基线：V13.2 `7fit-f111-v13_2-compact-reference-index.html`  
目标：从“单页资料堆叠”重构为“教练工作层 + 训练知识层 + 系统维护层”的多视图训练系统。

---

## 1. 设计目标

V14 不新增训练理论，不修改已经冻结的八大模式 V1.1、SUPPORT、CORE、F111 32 套课程、场馆动线和替换冲突逻辑。

V14 只解决一个核心问题：

> 当前所有课程、知识体系、编排规则、动作库、审计和开发资料都铺在同一长页面，导致日常编课路径过长、认知负担高、系统维护资料干扰教练使用。

重构后默认只暴露教练高频工作内容，低频规则和系统维护内容通过独立视图进入。

---

## 2. V14 一级导航

### 2.2 训练体系

定位：7Fit 教练知识库。

三个主要子页：

#### 八大动作模式
- 蹲
- 髋铰链
- 臀推 / 髋伸展
- 单腿
- 水平推
- 垂直推
- 水平拉
- 垂直拉

以 V1.1 为唯一当前基线。

每个模式显示：
- T1–T4 主链
- 每一级的能力意义
- 同级动作
- 推荐退阶
- 推荐进阶
- 教练观察指标

#### SUPPORT 支撑模式
- SUP-S1～SUP-S6
- 30 个规范支撑节点
- 同级替换
- 推荐退阶 / 进阶
- 空间和楼层提示

#### CORE 核心模式
- CORE-L1～CORE-L4
- Core Demand
- 同级同任务替换
- 同级不同任务
- 进退阶

课程中点击 SUPPORT / CORE 动作时跳入对应知识详情，而不是把整个知识库铺在课程页下面。

### 2.3 编排规则

定位：解释“系统为什么这样编”。

子页：

#### 场馆动线
正式 Strength Route：
`2F PREP → 1F STRENGTH → 2F RECOVERY → POST CARDIO`

#### 动作替换规则
- 同模式
- 同等级
- 场馆路由允许
- 可自动编排
- 不与当前课重复

#### 冲突检查
保留现有 V10/V13 逻辑：
- 动作重复
- 楼层冲突
- 编排状态
- 模式改变
- T 层级改变
- 器械集中
- 训练负荷集中
- SUPPORT / CORE 进退阶提醒

#### 进退阶判定
统一引用：
- 八大动作模式 V1.1
- SUPPORT S1–S6
- CORE L1–L4

这一页是规则说明，不承担日常编课。

### 2.4 动作库

定位：教练查动作 + 系统查数据。

默认界面不是 165 个超长动作卡全部展开，而是：

```
[搜索动作]

筛选：
模式 | T层级 | 区域 | 器械 | 类别 | 编排状态

动作结果列表
```

点击动作打开详情 Drawer / Modal。

动作详情包含：
- 名称
- 标准 ID（技术详情折叠）
- 模式
- T 等级
- 器械
- 区域
- 处方
- 教练口令
- 执行步骤
- 常见错误
- 注意事项
- 同级替换
- 退阶
- 进阶

#### 场馆替换矩阵
不再直接展示巨大矩阵。

矩阵继续作为系统数据存在。

用户查询某个动作时，详情中展示：

```
当前：哑铃卧推 T3
同级替换：上斜哑铃卧推
退阶：器械推胸 T2
进阶：杠铃卧推 T4
```

需要看完整矩阵时才进入“高级视图”。

#### Venue Overlay
场馆覆盖节点与 Excel 来源动作在这里显示来源关系。

## 6. 数据原则

### 不复制核心训练数据

V14 的页面拆分不能制造多份课程和动作数据。

所有视图共享同一数据对象：

- F111 Sessions
- Exercise Library
- Eight Pattern V1.1
- SUPPORT
- CORE
- Venue Routing
- Replacement Rules
- Audit Metadata

“编课中心”和“训练体系”只是同一数据的不同 projection。

### Source vs Standard 必须继续分开

保留：
- Excel Source Tier
- V1.1 Standard Tier
- Venue Overlay

不允许网页展示层静默改写源数据。

## 8. V14 首页成功标准

打开网站后，在不滚动长页面的情况下，教练应当能在 2–3 次点击内完成：

1. 选择一个 F111 Recipe；
2. 选择 L1–L4；
3. 查看完整课程；
4. 替换一个动作；
5. 看见替换后的 PASS / WARN / FAIL。

不需要先浏览任何开发版本、器械清单或审计资料。

## 10. 非回归要求

V14 结构重做后必须保证：

- F111 32/32 课程仍存在；
- A / B / C 主结构不丢失；
- SUPPORT 30 个规范节点不丢失；
- CORE 20 个规范节点不丢失；
- 八大模式 V1.1 主链不改变；
- V13 场馆覆盖动作不丢失；
- 2F → 1F → 2F 硬规则不改变；
- POST_CARDIO_ONLY 不进入 F111 正式训练；
- 所有替换选择仍运行冲突检查；
- 所有现有动作详情可被查到；
- Source 与 Standard 仍可追溯。

## 12. 最终定位

V14 不再是一张“什么都有的 HTML 页面”。

它应当成为：

> **7Fit 场馆训练知识库 + 教练编课工作台 + 系统维护控制台**

三个层级共享同一套训练数据，但分别服务不同使用场景。
