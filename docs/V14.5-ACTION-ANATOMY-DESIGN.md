# 7Fit Training System V14.5｜动作肌群解剖层设计规范

状态：设计冻结候选  
基线：V14.4 泡沫轴肌群匹配版  
目标：为 7Fit 动作库建立可复用的肌群/关节解剖数据层，使动作详情、热身匹配、泡沫轴匹配、训练量统计和重复刺激检查都由真实动作解剖数据驱动，而不是主要依赖动作模式推断。

## 1｜核心原则

V14.5 不改变既有八大主动作模式 T1–T4、SUPPORT S1–S6、CORE L1–L4 + Core Demand、PREP P1–P4、F111 32 套课程、2F PREP → 1F STRENGTH → 2F RECOVERY 和原替换冲突规则。本次只新增“动作肌群解剖层”。

不同动作类别使用不同显示语义：

- 力量动作：主要肌群｜辅助肌群｜稳定肌群
- SUPPORT / CORE：主要训练肌群｜协同肌群｜稳定作用
- 热身 / 激活：主要激活肌群｜辅助激活肌群｜主要活动关节
- 拉伸 / 活动度：主要伸展肌群｜辅助伸展区域｜目标关节
- 泡沫轴：主要松解组织｜相关肌群 / 区域｜安全避让区域

## 2｜统一数据结构

```js
anatomy: {
  roleType: "strength" | "support_core" | "activation" | "mobility" | "stretch" | "foam_roll",
  primary: ["股四头肌", "臀大肌"],
  secondary: ["大收肌", "腘绳肌"],
  stabilizers: ["腹内外斜肌", "竖脊肌", "臀中肌"],
  joints: ["髋关节", "膝关节", "踝关节"],
  movementActions: ["髋伸", "膝伸"],
  tissueTargets: [],
  avoidRegions: [],
  confidence: "high" | "medium" | "review",
  sourceNote: "7Fit V14.5 curated anatomy layer"
}
```

字段含义：
- primary：主要产生目标动作力矩，或该动作主要训练 / 激活 / 伸展 / 松解的组织。
- secondary：明显参与动作完成，但不是主要目标。
- stabilizers：主要承担关节、肩胛、骨盆、躯干或姿势稳定。
- joints：动作需要重点活动或控制的关节。
- movementActions：如髋伸、膝伸、肩水平内收、肩伸、肘屈等。
- tissueTargets：拉伸、泡沫轴类动作使用。
- avoidRegions：泡沫轴或拉伸安全边界。
- confidence：当前标签可靠程度。
- sourceNote：记录标签由何种系统规则或人工审查得出。

## 3｜解剖命名规范

优先使用教练容易理解的中文常用解剖名称：
胸大肌、背阔肌、三角肌前束 / 中束 / 后束、肱二头肌、肱三头肌、股四头肌、腘绳肌、臀大肌、臀中肌、内收肌群、腓肠肌 / 比目鱼肌、竖脊肌、腹直肌、腹内斜肌 / 腹外斜肌、腹横肌、前锯肌等。

避免：
- 为了“更专业”无限拆到非常细的小肌肉；
- 同一页面混用中文、拉丁名和英文缩写；
- 把髂胫束写成主动收缩肌肉；
- 把稳定肌随意写成原动机；
- 把肌电大小直接等同于长期训练效果。

## 4｜第一阶段覆盖范围

V14.5 第一阶段不直接自动填满全部 188 个动作。

Phase A｜必须高可信补齐：
1. 八大动作模式 T1–T4 主链；
2. F111 32 套课程实际调用的正式动作；
3. D1 / D2 常用辅助动作；
4. SUPPORT 30 个规范节点；
5. CORE 20 个规范节点；
6. PREP 20 个规范热身动作；
7. 泡沫轴 12 个规范节点。

Phase B｜动作库高频剩余动作：
主项力量、辅项力量、高频肩胛 / 手臂动作、高频热身激活动作。

Phase C｜完整动作库：
剩余恢复、拉伸、体能与低频动作。

## 5｜质量分级

每个 anatomy 记录必须带 confidence：

HIGH：
动作结构清楚，主要肌群和辅助 / 稳定关系明确，例如器械推胸、哑铃卧推、高位下拉、哈克深蹲、臀推、弹力带外旋。

MEDIUM：
受动作执行方式、握法、躯干角度、器械结构影响较明显，例如坐姿划船不同把位、地雷杆推举、单臂划船、部分复合体能动作。

REVIEW：
动作名称不足以确定执行细节，或场馆动作存在自定义版本，例如弹力带左右环绕、弹力带前外旋具体角度、名称不标准的旧动作节点。

confidence=review 的动作不进入精准肌群集中 WARN。

## 6｜网站 UI

动作详情页新增“肌群解剖”区。

力量动作示例：

```text
肌群解剖

主要肌群
胸大肌

辅助肌群
肱三头肌 · 三角肌前束

稳定肌群

```

Coach Mode 默认只显示主要肌群、辅助肌群、稳定肌群、主要关节。

## 7｜F111 课程中的肌群摘要

每套课程详情新增一个紧凑的“本节主要训练肌群”。

系统从当前已选择动作实时聚合：

```text
主要刺激
臀大肌 · 股四头肌 · 背阔肌

协同参与
腘绳肌 · 肱二头肌 · 臀中肌

核心 / 稳定
腹壁 · 竖脊肌 · 肩胛稳定肌
```

替换动作后实时重新计算。

## 8｜热身匹配升级

V14.4 PREP 主要根据下肢动作模式、上肢动作模式、Session L、Main T 推荐。

V14.5 调整为：

第一依据：当前主项实际肌群  
第二依据：主训练模式  
第三依据：Session / T 等级

热身排序：

```text
肌群需求
↓
关节需求
↓
动作模式需求
↓
Session / T 等级
↓
推荐 PREP
```

## 9｜泡沫轴匹配升级

V14.5 泡沫轴优先读取当天 A / B / D1 / D2 的主要肌群和辅助肌群。

示例：

```text
胸大肌 → 泡沫轴胸大肌
肱三头肌 → 泡沫轴肱三头肌
背阔肌 → 泡沫轴背阔肌/背侧
肱二头肌 → 泡沫轴肱二头肌
股四头肌 → 泡沫轴大腿前侧
腘绳肌 → 泡沫轴大腿后侧
臀大肌/臀中肌 → 泡沫轴臀部
内收肌群 → 泡沫轴大腿内侧
```

限制：
- 不是动作涉及某肌肉就自动必滚；
- 默认推荐最多 2–4 个高相关区域；
- 优先主要肌群，再看辅助肌群；
- 稳定肌群通常不自动进入泡沫轴推荐；
- 有安全限制的区域保留 Coach warning。

## 10｜肌群暴露统计

V14.5 第一版只做“动作暴露统计”，不宣称等同于真实生理训练量。

基础权重：

```text
主要肌群：1.0
辅助肌群：0.5
稳定肌群：0.25
```

系统只用于：
- 判断课程肌群覆盖；
- 发现明显重复堆叠；
- 帮助热身和泡沫轴排序。

不把这个数直接命名为：
- 有效组数；
- 肌肥大训练量；
- 热量；
- 生理刺激值。

## 11｜新增软性冲突提醒

新增：

`MUSCLE_CONCENTRATION`

触发：
- 替换动作后某肌群暴露分数显著高于默认方案；
- 同时达到系统阈值。

示例：

> 股四头肌刺激集中明显增加，请确认是否符合本节训练目标。

该提醒为 WARN，不是 FAIL。

## 12｜动作库 Excel 结构

不直接在原动作库 32 列主表中继续塞大量字段。

新增独立工作表：

`动作肌群解剖`

字段：
- 标准 ID
- 动作名称
- Role Type
- 主要肌群
- 辅助肌群
- 稳定肌群
- 主要关节
- 动作功能
- 主要组织
- 避让区域
- Confidence
- Source Note
- 验证状态

## 13｜数据治理规则

1. 不根据动作名称批量猜 188 个动作后直接标为已验证。
2. Phase A 必须人工规则审查。
3. 相同动作不同变式可以继承 base anatomy，但变式导致重点变化时要覆盖。
4. 握法、上斜 / 平板、胸托 / 无胸托、单侧 / 双侧等可影响 secondary / stabilizers。
5. confidence=review 不进入精准肌群集中 WARN。
6. Source anatomy 与系统推断 anatomy 必须可追溯。
7. anatomy 缺失不得阻断正常编课。

## 14｜V14.5 第一版交付

第一版必须包含：
- `动作肌群解剖` 数据层；
- Phase A 高可信动作解剖数据；
- 动作详情页肌群解剖区；
- F111 当前课程肌群摘要；
- PREP 基于肌群的二次排序；
- 泡沫轴基于肌群的二次排序；
- MUSCLE_CONCENTRATION soft WARN；
- 系统维护页 Anatomy Coverage；
- 未覆盖动作清单；
- 自动测试与非回归验证。

## 15｜非回归要求

V14.5 完成后必须保证：
- 32/32 F111；
- 8/8 八大模式 V1.1；
- 30/30 SUPPORT；
- 20/20 CORE；
- 20/20 PREP；
- 12/12 泡沫轴；
- 原替换冲突逻辑不回退；
- 场馆路由不改变；
- Source Tier / Standard Tier 不合并；
- anatomy 数据缺失时页面正常降级；
- 没有 anatomy 的动作仍可正常编课和替换。

## 16｜后续可扩展方向

V14.5 数据稳定后，再扩展：
- 单节课肌群覆盖图；
- 周期肌群训练频率；
- 连续课程肌群过度集中提醒；
- 女性塑形部位覆盖分析；
- 按目标肌群搜索动作；
- “重点练臀 / 背 / 肩”反向推荐模板；
- 自动生成 PREP + Foam Roll；
- 会员周期训练肌群平衡报告。

这些不进入 V14.5 第一版。
