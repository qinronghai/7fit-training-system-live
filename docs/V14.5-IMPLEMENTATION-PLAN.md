# 7Fit Training System V14.5｜动作肌群解剖层 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 V14.4 的既有训练系统上建立可追溯的动作肌群解剖层，为 Phase A 的 120 个唯一运行节点提供高可信解剖数据，并用它驱动动作详情、F111 肌群摘要、PREP/泡沫轴匹配和肌群集中 WARN。

**Architecture:** V14.5 保留 V14.4 的 `window.V14_DATA` 作为训练/动作/课程真值，新建独立 `window.V14_ANATOMY` 数据文件与 `V14Anatomy` 纯逻辑模块。解剖数据不反写或覆盖动作模式、T 层级、SUPPORT/CORE/PREP 等原字段；页面和冲突检查只通过 `V14Anatomy` 读取解剖层。Excel 新增独立工作表 `动作肌群解剖`，作为后续长期维护源。

**Tech Stack:** Static HTML/CSS, vanilla JavaScript, JSON-like JS data payloads, Python/pytest, Node.js syntax validation, artifact_tool for XLSX updates.

**Spec:** `/mnt/data/7Fit_Training_System_V14.5_动作肌群解剖层设计规范.md`

## Global Constraints

- 不改变八大主动作模式 T1–T4。
- 不改变 SUPPORT S1–S6。
- 不改变 CORE L1–L4 + Core Demand。
- 不改变 PREP P1–P4。
- 不改变 F111 32 套课程和 6 个正式槽位结构。
- 不改变 `2F PREP → 1F STRENGTH → 2F RECOVERY → POST CARDIO` 场馆路由。
- 原替换冲突规则继续生效。
- anatomy 数据缺失不得阻断编课、替换或动作详情。
- 不把肌群暴露分数称为“有效组数”“肌肥大训练量”“热量”或“生理刺激值”。
- `confidence=review` 的 anatomy 不参与精准 `MUSCLE_CONCENTRATION` WARN。
- 不通过动作名称批量猜测全部 188 个动作并标成“已验证”。
- Source / Standard / Venue Overlay 与 anatomy 必须保持分层、可追溯。
- 大腿外侧泡沫轴不把髂胫束定义为主动肌肉或“必须直接碾压的组织”。
- 竖脊肌泡沫轴继续使用“竖脊肌旁（胸腰段）”安全口径。

- 髋铰链主要肌群以臀大肌、腘绳肌为主；竖脊肌通常作为 stabilizer，不默认写成主要原动机。

- 水平拉：背阔肌、菱形肌/中斜方肌按具体动作角度标主要；肱二头肌/肱肌 secondary。
- 垂直拉：背阔肌 primary；肱二头肌/肱肌/大圆肌 secondary。
- 臀推：臀大肌 primary；腘绳肌/内收肌群 secondary；腹壁/臀中肌 stabilizers。
- 不把“核心”作为一个解剖肌肉名；需要时写腹壁，或具体腹直肌、腹内外斜肌、腹横肌。
