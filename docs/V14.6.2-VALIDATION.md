# 7Fit Training System V14.6.2｜通用模块复制系统验证报告

## 版本目标

V14.6.2 在 V14.6.1 的整节 F111 复制能力之上，增加网站级“复制本模块”通用能力，并重构教练版复制格式。

## 已实现功能

### 1. 通用“复制本模块”

已接入：

- F111 当前课程泡沫轴模块
- F111 当前课程 PREP 热身模块
- PREP 匹配器：泡沫轴推荐
- PREP 匹配器：动态热身 / 激活推荐
- PREP 单动作详情
- 泡沫轴单动作详情
- 动作库动作详情抽屉
- 八大动作模式详情
- SUPPORT 详情
- CORE 详情
- 编排规则页面

底层统一通过 `window.V14ModuleCopy` 生成纯文本并调用 Clipboard API，后续新模块可以继续复用。

### 2. F111 教练版复制格式升级

教练版动作统一输出：

```text
A｜哈克深蹲｜T3
3组 × 10次｜RIR≈3
```

不再输出：

- 器械名称
- 楼层
- 内部动作 ID
- Source Tier
- Venue Overlay
- 其他系统维护字段

### 3. 训练处方

复制内容优先读取当前动作 / 课程已有处方。

当源数据使用 RPE 时，复制层仅做可读性转换，例如：

```text
RPE 7 → RIR≈3
```

这里的 `≈` 明确表示近似换算，不把推导值伪装成源数据原值。

当前 F111 正式课程槽位检查结果：

```text
正式槽位处方可用        192 / 192
力量槽位带 RIR 信息     128 / 128
```

### 4. 会员版

会员版保留：

- 动作名称
- 组数
- 次数 / 时间
- 课前准备
- 主要训练部位
- 恢复 / 有氧提示

会员版隐藏：

- T 层级
- RIR
- 器械 / 楼层
- 内部 ID
- 冲突代码
- 系统审计字段

## 浏览器 smoke 状态

当前执行环境中的 Chromium 被组织策略禁止访问 localhost、file:// 和 data: 本地页面，导航均返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。

因此本版本**没有声称真实浏览器 smoke PASS**。该限制来自执行环境 URL 策略，而不是通过浏览器发现了应用运行错误。

现阶段验收依据为：

- Python 结构 / 非回归测试
- JavaScript runtime formatter tests
- JavaScript syntax validation
- 资源路径完整性检查
- 单文件 preview 静态构建检查

部署到正常 HTTPS 环境后，应补一次真实移动端点击复制 smoke 作为部署验收。

## 发布结论

V14.6.2 的通用复制逻辑、教练版处方格式和会员版字段过滤已经通过自动化验证；浏览器本地 smoke 因当前环境策略被阻断，保留为部署后补验项目。
