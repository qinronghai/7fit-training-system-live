# 7Fit Training System V14.6.3｜十大动作模式整合版设计规范

状态：设计冻结候选  
基线：V14.6.2｜通用模块复制系统  
目标：将现有“八大动作模式 + SUPPORT + CORE”统一升级为对外正式的“十大动作模式”信息架构，同时保留底层 T / S / CORE-L 三套独立能力等级，不破坏 F111、PREP、Foam、Anatomy、Conflict 与复制系统。

---

## 1｜正式定义：十大动作模式

7Fit Training System 对外统一使用：

# 十大动作模式

| 编号 | 动作模式 | 等级体系 |
|---|---|---|
| 01 | 蹲模式 | T1–T4 |
| 02 | 髋铰链 | T1–T4 |
| 03 | 臀推 / 髋伸展 | T1–T4 |

| 05 | 水平推 | T1–T4 |
| 06 | 垂直推 | T1–T4 |
| 07 | 水平拉 | T1–T4 |

> **支撑模式**

不使用“支持模式”。

## 2｜核心架构原则

### 2.1 对外 10 个模式，对内保留原有能力系统

不能把 SUPPORT / CORE 强改成 T1–T4。

正式内部结构：

```text
十大动作模式
├── 01–08 主动作模式
│   └── T1–T4
├── 09 支撑模式
│   └── SUP-S1–SUP-S6
└── 10 核心模式
    ├── CORE-L1–CORE-L4
    └── Core Demand
```

因此：

- T = 主动作模式能力层级；
- S = 支撑任务复杂度；
- CORE-L = 核心训练难度；
- Core Demand = 核心功能需求。

三者不能互相替代。

---

## 3｜数据结构

### 3.1 保留 `eightPatterns`

现有底层：

```js
V14_DATA.eightPatterns
```

继续保留，仍只负责 8 条 T1–T4 力量主链。

原因：

- F111 主项匹配依赖它；
- PREP / Foam 当前模式匹配依赖它；
- replacement / conflict 依赖它；
- Venue Overlay 和 Standard Tier 依赖它。

不得直接改成 10 个混合结构。

### 3.2 新增上层目录 `tenPatternCatalog`

建议新增：

```js
V14_DATA.tenPatternCatalog = [
  {
    id: "PATTERN-01",
    type: "main_pattern",
    key: "squat",
    name: "蹲模式",
    levelSystem: "T1-T4"
  },
  ...
  {
    id: "PATTERN-09",
    type: "support",
    key: "support",
    name: "支撑模式",
    levelSystem: "SUP-S1-S6"
  },
  {
    id: "PATTERN-10",
    type: "core",
    key: "core",
    name: "核心模式",
    levelSystem: "CORE-L1-L4+DEMAND"
  }
];
```

此 catalog 只负责：

- 导航；
- 信息架构；
- 十大模式首页；
- 复制文本；
- 统一展示。

不成为 F111 主动作模式算法的替代品。

## 5｜第 09 模式：支撑模式

正式名称：

# 09｜支撑模式 SUPPORT

保留当前 SUPPORT 30 个 canonical node。

等级：

```text
S1 基础静态支撑
↓
S2 减少支点
↓
S3 动态支撑
↓
S4 身体位移
↓
S5 旋转
↓
S6 单侧整合
```

教练理解口径：

> 撑住 → 少一个支点 → 动起来 → 身体位移 → 旋转 → 单侧整合

不得改成 T1–T4。

---

## 6｜第 10 模式：核心模式

正式名称：

# 10｜核心模式 CORE

保留当前 CORE 20 个 canonical action。

等级：

```text
L1 基础控制
↓
L2 标准抗伸展
↓
L3 多方向稳定
↓
L4 高负荷 / 长杠杆整合
```

同时保留：

# Core Demand

包括但不限于：

- 抗伸展
- 抗旋转
- 抗侧屈
- 动态旋转
- 呼吸 / 腹压协调
- 负重整合

规则继续保持：

> Session L4 不代表核心动作必须使用 CORE-L4。

核心选择仍需考虑：
- 疲劳；
- 动作质量；
- 当天主项；
- Core Demand；
- 会员能力。

## 7｜F111 保持原结构

F111 仍然是：

> 一下肢 + 一上肢 + 一支撑

第一排：

```text
A 下肢主项
B 上肢主项
C 支撑
```

第二排：

```text
D1 下肢辅助
D2 肩胛 / 手臂
CORE
```

虽然 SUPPORT / CORE 被纳入“十大动作模式”，但：

- SUPPORT 仍是 F111 第三个“1”；
- CORE 仍是第二排 CORE 槽位；
- 不增加新的正式 F111 主项槽位；
- 不允许“一节课堆十个模式”。

---

## 8｜PREP / Foam 匹配规则

PREP / Foam 当前主要依据 8 个主训练模式和实际 anatomy。

V14.6.3 不强制让 SUPPORT / CORE 进入主模式泡沫轴算法。

原则：

```text
主项 A/B/D1/D2
→ anatomy
→ PREP / Foam
```

SUPPORT / CORE：

- 可以影响核心 / 肩胛稳定类 PREP；
- 不作为主要泡沫轴推荐来源；
- 不改变当前 2–4 个泡沫轴推荐上限。

---

## 9｜Anatomy 保持不变

239/239 Runtime Anatomy 不需要重做。

“十大动作模式”属于：

> 训练分类 / 信息架构

而 anatomy 属于：

> 动作功能 / 肌群解剖层

两层继续独立。

## 14｜版本定位

正式版本：

# V14.6.3｜十大动作模式整合版

核心定义：

> **8 个主动作模式 + 1 个支撑模式 + 1 个核心模式 = 7Fit 十大动作模式**

不是简单把 8 改成 10，而是把原本已经独立成熟的 SUPPORT 与 CORE 正式纳入训练体系顶层导航，同时保持各自的等级和功能逻辑。
