# 7Fit PREP 热身体系 V1

## 定位

PREP 是独立于八大主动作 T1–T4、SUPPORT S1–S6、CORE L1–L4 的热身准备层。

- **PREP P1**：基础准备——高稳定、低协调、低疲劳。
- **PREP P2**：动态准备——加入动态活动、弹力带或肢体移动。
- **PREP P3**：整合准备——多关节、单侧或多平面整合。
- **PREP P4**：专项准备——预留给爆发、跳跃、投掷等更高协调专项热身；当前批次暂不使用。

> 关键原则：热身不是越难越好。P 等级只表示热身动作本身的协调/整合要求；实际选择仍要匹配当天主训练模式、Session L 等级和主训练 T 层级。

## 主训练匹配原则

1. **先看主训练模式**：下肢日优先匹配髋、踝、后侧链、髋稳定；上肢日优先匹配肩关节、胸椎、肩袖与肩胛。
2. **再看 Session L 等级**：L1 以 P1 为主；L2 可加入 P2；L3–L4 可使用 P2–P3，但不强制追求更高难度。
3. **再看主训练 T 层级**：T1–T2 更强调动作学习与基础准备；T3–T4 更强调与当天主项动作的专项对应。
4. **热身不做到力竭**：目标是提高准备度、动作质量和关节可用性，不消耗主训练能力。
5. **路线固定**：F111 力量课默认在 2F 完成 PREP，再一次下楼进入 1F STRENGTH。
