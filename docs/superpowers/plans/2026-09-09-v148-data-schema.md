# V14.8 Data Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add versioned JSON Schema contracts, repository-wide cross-reference validation, mutation-based negative tests, and CI gating for the current V14.7 runtime data without changing training semantics.

**Architecture:** Keep the browser runtime dependency-free. Store Draft 2020-12 schemas under `schemas/v14.8/`; use a Python validator in `tools/` to parse `window.V14_DATA`, validate records with `jsonschema`, then apply cross-record invariants that JSON Schema cannot express reliably. Gate both PR verification and Pages deployment with the same validator.

**Tech Stack:** JSON Schema Draft 2020-12, Python 3.13, `jsonschema`, pytest, existing Node.js 22 runtime tests, vanilla JS static app.

**Spec:** `docs/superpowers/specs/2026-09-09-v148-data-schema-design.md`

## Global Constraints

- Preserve V14.7 training semantics exactly.
- Keep `system-data.js` monolithic in #3; data splitting belongs to #4.
- Preserve 32 F111 sessions, 8 Recipe Families, 30 SUPPORT nodes, 20 CORE nodes, 20 PREP nodes, and 12 Foam nodes.
- Preserve F111 = 一下肢 + 一上肢 + 一支撑.
- Preserve Session L independence from Main T / SUPPORT S / CORE-L.
- Preserve #5 policy: D1/D2 auxiliary routes are `1F_ONLY`; formal main slots may use `1F_ONLY + FLEX_1F_2F`.
- `POST_CARDIO_ONLY` / `CONDITIONING_2F` / `RECOVERY_2F` must never enter formal F111 strength slots.
- Browser runtime must not depend on Python or `jsonschema`.

```python
def load_runtime_data(path: Path) -> dict:
    text = path.read_text(encoding="utf-8")
    match = re.search(r"window\.V14_DATA\s*=\s*(\{.*\});\s*$", text, re.S)
    if not match:
        raise ValueError("window.V14_DATA payload missing")
    return json.loads(match.group(1))
```

Use `Draft202012Validator` for per-record validation. Sort errors by JSON path before formatting.
