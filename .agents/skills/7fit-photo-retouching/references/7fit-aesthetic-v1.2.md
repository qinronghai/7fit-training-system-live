# 7Fit 摄影美学标准 V1.2

**经用户确认的日常宣传照片审美基准：明亮通透、人物肤色自然柔和、环境干净、人物立体、构图专业、低 AI 感，不刻意改变身材。**

## 风格定位

7Fit 是面向女性的小而美私教健身场馆。画面追求自然的商业运动摄影，不是影楼磨皮、假高光或过度电影色调。

- **光线**：整体明亮、柔和、透气；人物高于或等于背景的视觉权重。提亮阴影但保留窗帘、白墙和服饰的高光细节。禁止假发光边缘、整片漂白的墙壁和皮肤。
- **肤色**：自然中性略暖，肌肤质地真实；不夸大健康红润，不发橙、不泛灰、不“奶油塑料皮”。皮肤细节、锁骨、肩背肌肉轮廓来源于真实姿态，禁止凭空强化。
- **空间**：白墙是干净的白而不是刺眼的纯白；黑色地胶、黑衣和器械有层次；背景简洁，但实物、真实窗格、器械、Logo 的结构可追溯。
- **质感**：低到中度饱和、清楚但不过度锐化、柔和而有适量反差。头发和织物细节必须真实。
- **构图**：突出训练者和动作，优先安全裁掉大面积无信息天花板、空白墙；保留整个人体动作链、握持、落脚、弹力带、哑铃、器械重量信息。
- **品牌**：已有真实 Logo 和场馆标识按原图保留，不重写为“7FIT”“7FITNESS”等替代版本；用户未要求的设计、广告文案和贴图不额外添加。

## 日常运营路由

1. 日常课程、场馆、生活方式照片：`EDITORIAL_ENHANCE`，允许生成式辅助，但必须通过原图比对；如果局部遮罩 / 合成不能保持人、器械、Logo，退回非生成式。
2. 教练教学、专业动作记录：`DOCUMENTARY_LOCKED`，非生成式，允许轻微曝光/白平衡与不损失训练信息的单张输出。
3. 体态评估、前后对比、改善成果：`EVIDENCE_LOCKED`，严格非生成式，不改体态、身材比例、背景透视，禁止误导性视觉对比。
4. 创意海报、复古风、人物合成：`CREATIVE_COMPOSITE`，用户明确指定时允许生成，标明创作性质而非证据。

## 生成式辅助安全提示词（需要已授权图像工具；不是像素精确保证）

> 仅将用户提供的原始照片作为编辑目标。保持同一人物、同一训练瞬间、关节角度、肌肉轮廓、肤色身份特征、服装、握持、器械、场馆标志和所有已有文字，不要重新构造环境。改善自然柔光、曝光平衡、肤色通透、背景洁净与专业构图。不得瘦身、拉高、改腿臀腰线、增肌、改变肩胛/骨盆位置、夸张磨皮、创造额外训练装备或更换墙面标志。以柔和真实的高级运动摄影效果为目标；仅在保真前提下对非关键背景做轻微局部清理。生成结果须与原图并排核验，隐私处理必须在最终交付前另做。

这套提示词降低风险，**不保证**模型遵守全部几何、Logo 和器械字符约束。若发现任何结构漂移，停止把该输出当真实纪实修图。

## 末端人脸隐私检查

- 露脸、低头露部分五官、侧脸、镜面反射均计入；背对镜头且没有可见五官的通常无需打码。
- 统一使用清晰边界但柔和过渡的高斯模糊，只覆盖必要的可见脸部区域；不得把整块头发、手臂、服装模糊。
- 即使生成引擎已经输出看似模糊的人脸，也要从最终图重新确认隐私，必要时使用基于最终像素的独立高斯模糊。
- 真实姓名、地址、会员账号、EXIF GPS 和明显背景身份线索可能仍有风险，必须由人核对。

## 视觉验收：通过 / 不通过

通过：柔和自然；人物更通透；暗部有细节；画面干净；动作完整；五官隐私处理到位；真实 Logo 和器械结构原样；没有新增人体形态特征。

不通过：脸/身形被重新生成；肌肉轮廓和骨盆位置变化；器械、数字或衣服细节错乱；白墙/肤色大面积过曝；强烈 AI 塑料感；裁断手脚或训练器械；打码不充分；未经用户同意把会员照片交给第三方服务。

## 输出约定

- 每张照片独立导出，默认保留原比例版本，可另做经确认的 4:5、9:16。
- 对生成式辅助编辑标记 `method: generative_assisted`；严格纪实标记 `method: source_only`。对外呈现用途遵循真实、非误导原则。
- 先质量审核，再交付；不把自动化检查误称为人工隐私合格证明。

该标准是 **V1.2 视觉规范**，不表示 Python V1.1 已具有生成式接口。
